# Checkpoints (all phases)

Tick these in your weekly log. Do not skip Phase 0–1.

## Phase 0 — Core literacy

- [ ] Explain packet, port, process, log
- [ ] Administer a Linux VM from the terminal
- [ ] Run [practice/read_log.py](practice/read_log.py) on the sample log

## Phase 1 — Security foundations

- [ ] Describe how a web request is authenticated
- [ ] List where secrets must not live
- [ ] Optional: Security+ study complete

## Phase 2 — Defense

- [ ] Flag abnormal lines in the sample auth log and propose host changes
- [ ] One-page IR outline (identify → lessons learned)
- [ ] One documented hardening change on *your* VM

## Phase 3 — Authorized labs

- [ ] Beginner path completed on an official lab platform
- [ ] 5–10 write-ups that include **remediation**
- [ ] Never practiced on unauthorized targets

## Phase 4 — AppSec

- [ ] Threat model of one feature you built
- [ ] Controls listed (added or planned)
- [ ] Dependency/lockfile hygiene on *your* repo

## Phase 5 — Career

- [ ] Portfolio of lab write-ups + fixes
- [ ] Target role chosen (SOC, AppSec, or pentest-after-IT)
- [ ] Bounty only after labs, in-scope programs only
