# Phase 5 — choose your target role path

You do not need to decide forever. Pick the **first job you will realistically apply for** in the next 3–6 months.

## Decision worksheet

| Question | Lean SOC if… | Lean AppSec if… | Lean pentest (later) if… |
| -------- | ------------ | --------------- | ------------------------ |
| Do you enjoy reading logs and alerts? | yes | sometimes | rarely at first |
| Do you ship or maintain code? | no | **yes** | sometimes |
| Phase 2 defense checkpoints done? | **priority** | nice to have | required eventually |
| Phase 3 authorized labs done? | helpful | helpful | **required** |
| Comfortable explaining fixes to devs? | moderate | **high** | high |

## Recommended default for this repository

You built and secured **Hotspot Messenger**. That is strong evidence for **junior AppSec** or **developer-with-security-focus** roles — *if* you also have general IT literacy (Phase 0–1).

If you have **no IT job yet**, many people still start with **help desk → SOC** while keeping AppSec portfolio pieces on the side.

## Path summaries

### A — SOC analyst (most common junior hire)

**Timeline:** Phase 2 complete + Security+ or Google cert progress  
**Portfolio:** log triage write-ups, IR outline, one VM hardening doc  
**Apply when:** you can walk through a suspicious auth log line-by-line

### B — AppSec engineer (you write software)

**Timeline:** Phase 4 complete + 3+ remediation write-ups  
**Portfolio:** threat models, ASVS checklist, code fixes in *your* repo  
**Apply when:** you can explain STRIDE on a feature you built

### C — Junior pentester (after IT + labs)

**Timeline:** IT ops experience **plus** Phase 3 lab hours (not before)  
**Portfolio:** 5–10 authorized lab write-ups with remediation  
**Apply when:** hiring manager sees sustained lab platform history, not just videos
