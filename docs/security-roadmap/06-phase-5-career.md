**Week 1 goal:** 3 remediation write-ups from *your* project + pick a target role path.

## Portfolio

- Lab write-ups + remediations only
- No dumps from live systems
- Prefer: “weakness class, impact, how we fixed it”

## Jobs (typical paths)

- Help desk / IT support → **junior SOC** (most common with Phase 2)
- If you already ship code → **junior AppSec** (Phase 4)
- **Junior pentester** usually needs IT background plus many authorized lab hours first (Phase 3)

Do not expect a pentest job from videos alone.

## Bug bounty

- Only programs with a **published policy**
- Stay in scope
- Report; do not “prove” impact with extra access
- Start **after** Phase 3, not before

## Keep skills from rotting

Keep one home lab VM running. Revisit Linux, logs, and one authorized lab room per month after the main path.

## Checkpoint

- [ ] 5–10 remediation-focused write-ups you could show a hiring manager
- [ ] Resume line: home lab + Security+ or Google cert and/or CySA+ path and/or lab platform progress
- [ ] If applying: target SOC or AppSec junior roles first unless you already have IT operations experience
