# Phase 3 — Authorized pentest labs (months 11–16)

Closest **legal** analogue to “hacking.” Practice **only** in purpose-built environments you are licensed to use.

This guide names platforms and certs. It does **not** include exploits, payloads, or attack procedures.

## Allowed platforms

- TryHackMe guided paths (Pre-Security if needed, then Jr Penetration Tester-style paths)
- Hack The Box **starting** machines you are licensed to use
- PortSwigger Web Security Academy **inside their labs**
- Local: vendor-provided intentionally vulnerable VMs **labeled for education**
- CTFs you **register** for

Never: real companies, schools, friends’ Wi‑Fi or accounts, or random public IPs.

## Rules

- Stay inside the lab’s network and written rules
- Focus on **why** a control failed and **how to patch/harden**
- No scanning random IPs
- Do not keep a personal “exploit toolkit” for real targets
- Every finding: fill [templates/lab-writeup.md](templates/lab-writeup.md) including **remediation**

If you cannot state the fix, you are collecting tricks, not learning security.

## Cert sequence (high level)

1. Several months of beginner authorized labs first
2. Then eJPT or PNPT-class exams
3. OSCP-class exams only after many lab hours (endurance tests, not a first cert)

## Checkpoint

- [ ] Complete a beginner authorized path on a platform above
- [ ] Produce **5–10** lab write-ups that include remediation (copy the template for each)
- [ ] Keep write-ups in a private notes folder or a repo that does not dump live-target data
