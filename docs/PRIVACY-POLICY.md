# Privacy Policy — Hotspot Messenger

**Last updated:** August 20, 2026  
**App:** Hotspot Messenger (`com.hotspot.messenger`)

## Summary

Hotspot Messenger is a **local network chat app**. Messages are sent between devices on the same Wi‑Fi or hotspot. We do **not** operate a cloud server and we do **not** collect your personal data on our servers.

## What data the app uses

| Data | Where it stays | Why |
|------|----------------|-----|
| Display name & avatar | Your device + host server on LAN | So others see who is chatting |
| Chat messages | Host device running the server | Local group/DM chat |
| Uploaded files | Host device (`data/uploads/`) | Shared images/files in chat |
| Server URL | Your phone storage (local) | Reconnect to the chat server |
| Notification preferences | Your phone storage (local) | Sound, vibration, alerts |

## What we do NOT do

- No account sign-up with us
- No analytics or advertising SDKs in the app
- No selling or sharing of your data
- No internet cloud backup of your chats (unless you host on a public server yourself)

## Permissions (Android)

| Permission | Purpose |
|------------|---------|
| Internet | Connect to the LAN chat server |
| Camera | Scan QR codes to join a server |
| Notifications | Alert you about new messages |
| Vibrate | Optional vibration on new messages |

## Children

This app is not directed at children under 13. We do not knowingly collect data from children.

## Changes

We may update this policy. The latest version is in the app repo at `docs/PRIVACY-POLICY.md` and on the host page at `/privacy.html`.
